# Greengo for VS Code

Greengo, the little green cowboy robot, rides along while Claude Code works, now right in VS Code:

- **Status bar:** a compact Greengo at the bottom right. Click him to open his panel.
- **Greengo panel:** the full look, with his straw boater, colors and animation.

He follows whichever Claude Code session was active most recently, in the chat panel or the terminal.

This extension shows Greengo; his personality lives in `~/.claude/greengo/greengo.sh`, which the main installer sets up. See the [Greengo repository](https://github.com/vedjuk/greengo) for installation and docs.
