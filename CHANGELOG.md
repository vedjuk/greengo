# Changelog

All notable changes to Greengo are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Greengo in the Claude desktop app: a Claude Code mod draws him above the prompt in the Code tab, which shows no terminal status lines. The installer sets it up and the uninstaller removes it.

## [1.0.0] - 2026-10-13

The first ride.

### Added

- Greengo in Claude Code's status line: a green cowboy robot in a straw boater, with a half-height crown on an underlined brim.
- Moods driven by Claude Code hooks: boot, listen, blush, work, wait, error, happy, idle and sleep.
- More than 140 lines, with nods to classic Westerns and cowpoke coding talk, picked at random.
- Faces with range: stone cold with a cigarillo, gunslinger squint, rough, smug, weary late at night, and the occasional grin.
- Animation: lasso swing, hat tip, cigarillo smoke, blinking, snoring and sleep-talk.
- A horse ♞ for each running subagent, and a battery meter for the context window.
- `/greengo` command: name, color, hat on or off, hide or show, stats.
- VS Code extension with a compact status bar Greengo and a full Greengo panel, following the latest active session, including the chat panel.
- Installer and uninstaller that keep your other settings, back them up, and restore your previous status line.
- Smoke test, extension test and CI on macOS and Ubuntu.
